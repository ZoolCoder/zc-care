= IntelliJ IDEA and Neovim
:description: IntelliJ IDEA through JetBrains Toolbox, and Neovim in the terminal.

IntelliJ IDEA is the editor for Java and Spring Boot; JetBrains Toolbox installs and updates it. Neovim covers quick edits in the terminal, and `vim` and `vi` open it.

== On the workstation

* `jetbrains-toolbox` cask and `neovim` formula.
* IntelliJ's editor and terminal fonts are set to JetBrains Mono Nerd Font by a setup script.

== Keys and commands

[%header,cols="1,2"]
|===
|Key or command |Does

|Hyper+I |Open IntelliJ IDEA
|`vim file` |Neovim
|===
